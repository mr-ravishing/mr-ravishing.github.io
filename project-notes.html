Sync with GitHub

Your notes are saved as a file in your own GitHub repository, so you can open them on any device.

  1. On GitHub, create a private repository, for example my-notes.
  2. Open Settings › Developer settings › Personal access tokens › Fine-grained tokens and generate a token. Under Repository access pick only that repository. Under Permissions, set Contents to Read and write.
  3. Enter the details below. Do the same on each device you use.

The token is kept only in this browser on this device. It is never written into your notes.

Changes sync automatically a few seconds after you stop writing, and whenever you reopen the app. If the same page was edited on two devices, the newer edit is kept.
